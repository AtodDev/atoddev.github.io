Confidentiality Policy

1. Purpose and Scope

This Confidentiality Policy defines how AtodDev handles, secures, and protects proprietary information, software code, user data, and developmental assets related to the mobile application Pixel Cookbook. This Policy applies to all internal team members, contractors, open-source contributors, and third-party partners who interact with our development environment or database services.

2. Definition of Confidential Information

Confidential Information includes any non-public data disclosed by us or stored within our project infrastructure, including but not limited to:

  • Source Code & Architecture: Proprietary Flutter applications, C++ hardware visual simulation logic, shaders, custom system scripts, or database architecture designs.
  • Authentication & Credentials: API keys, Firebase configuration payloads, security certificates, encryption keys, and server passwords.
  • User Data: Personal identifying details, emails, authentication profiles, or custom recipes stored privately.
  • Business Assets: Unreleased feature roadmaps, pixel-art graphics, audio compositions, and strategic deployment timelines.

3. Obligations and Safeguards

All individuals granted access to our systems must strictly adhere to the following security principles:

  • Access Control: Granted on a strict need-to-know basis.
  • Credential Hygiene: Must never be committed to public version-control branches.
  • No Disclosure: Must not be distributed, published, or discussed with external third parties without authorization.
  • Data Minimization: No personal data shall be pulled unless explicitly required to maintain functionality.

4. User Data Protection

We treat player and user data with absolute privacy. User-generated content, account settings, and personal emails will be stored securely using Firebase Authentication and Cloud Firestore security rules. We enforce policies that ensure no automated or human tracking monitors private database metrics for non-essential use. User data remains confidential and is never sold, traded, or shared with third-party advertising brokers.

5. Breaches and Enforcement

Any unauthorized distribution, exposure, or leakage of our source files, credentials, or user information constitutes a violation of this Policy. AtodDev reserves the right to immediately terminate access permissions, remove open-source contributor status, and pursue necessary legal or administrative actions to protect our intellectual property and community privacy.
